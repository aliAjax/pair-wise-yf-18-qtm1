# hxyfront-62006 返修换石台 · 珠宝镶嵌工作室

面向珠宝镶嵌工作室的返修换石前端系统，替代便签管理拆下的旧宝石与替石。

## 功能

- **返修工单**：按订单查看戒指镶嵌位（主石位 / 围石 / 副石），附镶嵌位置示意图，点击图节点可定位到对应镶嵌位卡片。
- **旧石处置**：拆下的旧宝石记作「报废」或「留库」，原位置随即空出，支持撤销拆石。
- **替石筛选分配**：按尺寸范围（默认原石 ±0.2mm 公差）、颜色下限、净度下限、编号筛选库存替石，分配到空出的镶嵌位。
- **占用拦截**：已分给别的订单的替石不可选，并显示占用订单编号。
- **换石校验**：尺寸差超出 ±0.2mm 公差，或颜色、净度低于原石的替换不能确认；拦截原因与原石信息自动留存到拦截记录。
- **批次留痕**：每次换石生成批次号，按订单（或全部订单）查看新旧宝石变更记录；报废、留库、待镶嵌空位、已换石数量随操作实时更新。
