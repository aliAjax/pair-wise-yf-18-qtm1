# hxyfront-62006 返修换石台

面向珠宝镶嵌工作室的返修换石工作台：戒指返修拆下的旧宝石登记报废或留库后，镶嵌位随即空出；按尺寸、颜色、净度筛选替石并分配到镶嵌位，已分给其他订单的替石会被挡住并显示占用订单编号；替换时尺寸差超出公差，或颜色、净度低于原石的，不能确认并保留拦截原因与原石信息；批次结算后生成订单的新旧宝石变更记录，报废、留库、待镶嵌数量随操作实时更新。

## 功能

- **镶嵌位示意图**：戒指主石位 / 围石位图形化展示，按 待拆 / 空位 / 待镶嵌 / 已镶嵌 着色，点选操作
- **旧宝石处置**：记报废或记留库，原位置立即空出；留库旧石自动回到替石库
- **替石筛选**：尺寸范围（mm）、颜色等级、净度等级、种类、仅在库，支持一键“匹配原石”
- **占用拦截**：已分配替石显示占用订单编号，确认时被挡住并留痕
- **换石校验**：尺寸差超公差、颜色 / 净度低于原石、种类不符均不能确认，拦截记录保留原因与原石信息
- **批次结算**：待镶嵌位完成换石，生成新旧宝石变更记录（可按订单查看）
- **实时计数**：报废、留库、待镶嵌、拦截记录数量随操作更新
